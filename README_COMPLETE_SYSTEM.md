## 🔧 TROUBLESHOOTING

### Legend Not Showing
1. Check browser console (F12)
2. Verify compliance-widget-v3.js loaded
3. Check for CSS errors
4. Clear browser cache
5. Hard refresh (Ctrl+Shift+R)

### Folios Show All Aircraft
1. Check URL has `?aircraft=ZS-XXX` parameter
2. Open console, look for filter message
3. Verify folio-system.html is V3
4. Clear localStorage and retry

### Highveld Shows No Data
1. Check console for error messages
2. Verify aircraft-config-data.js has ZS-AAM
3. Check org name is 'highveld' (lowercase)
4. Clear cache and retry

### Files Not Loading
1. Check all 17 files uploaded
2. Verify files in same directory
3. Check file permissions
4. Look for 404 errors in console
